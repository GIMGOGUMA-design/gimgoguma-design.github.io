# TradingDeskPro website

Product introduction for TradingDeskPro, a native Windows trading workspace.

Website: https://gimgoguma-design.github.io/

This repository contains only the static product website and four isolated application screenshots with simulated data and orders disabled. The native application source, credentials, training data and user records are not included.

## Website

- Korean and English, responsive desktop/mobile layouts.
- Interactive previews for two to five charts.
- Free/Max comparison, FAQ and official Windows release downloads.
- No accounts, payment processing or real trading on this website.

## Deployment

GitHub Pages publishes the `main` branch root. `.nojekyll` serves the static files directly. Keep assets relative to the page and update the canonical/Open Graph URLs if the site address changes. No build or package installation is required.

## Product scope

Product details describe Windows 1.7.1 Stable. AI automation uses paper funds; real API AI assistance requires two warnings and an explicit final confirmation for every order. API availability depends on provider, region and account permissions. The Max subscription link opens the existing separate subscription service.

Application releases: https://github.com/GIMGOGUMA-design/TradingDeskPro-Releases/releases

1.6 adds local result images, reviewed community templates and Max selected public profiles. Hosted public pages remain on the existing separate account service. Site download sizes/checksums come from the inspected1.6 binaries. PLUS is scheduled separately for1.7.1.

PLUS is USD4.99/month with four charts; Max USD9.99 includes PLUS and five charts. Download hashes/sizes match the frozen1.7.1 Windows binaries.

Checkout plan/language hints preserve pending-purchase ownership and never start a purchase automatically.
